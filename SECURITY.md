# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | ✅ |

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** (private advisory) for anything that could affect real deployments — authentication bypasses, path traversal, session issues, setup-window abuse.

Please include: affected version, environment (Windows/Linux, desktop or headless), steps or a proof of concept, and your assessment of impact.

You'll get an acknowledgement within a few days, a fix timeline after triage, and credit in the release notes (unless you prefer to stay anonymous). Please avoid public disclosure until a fixed release is out.
